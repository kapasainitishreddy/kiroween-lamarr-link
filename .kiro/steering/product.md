# Lamarr Link — Product

Stitch Hedy Lamarr’s 1942 frequency-hopping patent concept with modern multi-agent communication and a live visual simulator.

**Users**: People interested in historical patents + modern agentic systems.

**Goals**:
- Visual demonstration of synchronized frequency hopping
- Agents that can only communicate when frequencies match
- Simulated jamming with adaptive recovery
- Clear historical context
